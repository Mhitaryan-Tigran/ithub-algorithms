# КТ. Алгоритм Дейкстры

Оба алгоритма реализованы и проверены в `python3 dijkstra_kt.py`.

## Задача 1. Задержки в сети

**Модель.** Неориентированный взвешенный граф G: вершины — r маршрутизаторов, рёбра — провода, вес ребра — длина w в метрах (целое положительное). S — множество точек входа. Задержка маршрутизатора v — это d(v), длина кратчайшего пути от v до ближайшей точки из S. Нужно найти сумму d(v) по всем v.

**Сведение к одной задаче.** Добавим фиктивную вершину s и соединим её рёбрами веса 0 со всеми точками входа. Тогда d(v) — обычное кратчайшее расстояние от s, и хватает одного запуска Дейкстры. В коде фиктивная вершина не создаётся: все точки входа сразу кладутся в очередь с расстоянием 0 (многоисточниковый Дейкстра).

**Почему обычный Дейкстра не подходит.** С двоичной кучей он работает за O((r + E) log r), а нужно O(r).

**Алгоритм за O(r) — Дейкстра с «корзинами» (алгоритм Дайала).**

1. Пусть L — суммарная длина всех проводов, по условию L ≤ 100r. Любой кратчайший путь проходит по каждому проводу не больше одного раза, значит любое d(v) ≤ L.
2. Создаём массив из L + 1 корзин: B[0], B[1], …, B[L]. В корзине B[d] лежат вершины с текущей оценкой расстояния d.
3. Всем точкам входа ставим d = 0 и кладём их в B[0], остальным d = ∞.
4. Идём по корзинам d = 0, 1, …, L. Для каждой вершины v из B[d], если её оценка всё ещё равна d (иначе это устаревшая запись), просматриваем соседей u по проводам длины w: если d + w < d(u), то d(u) = d + w и u кладётся в B[d + w].
5. Когда все корзины пройдены, d(v) — окончательные задержки. Ответ — сумма d(v).

**Корректность.** Корзины просматриваются в порядке возрастания d, поэтому вершины извлекаются в том же порядке, что и в обычном Дейкстре: при извлечении из B[d] у вершины уже минимальное расстояние, ведь все веса положительны и любая более короткая оценка лежала бы в корзине с меньшим номером, которая уже обработана.

**Время работы.**

- Число проводов E ≤ L ≤ 100r, потому что каждый провод не короче 1 метра. Значит E = O(r).
- Создание и просмотр L + 1 корзин — O(L) = O(100r) = O(r).
- Каждый провод релаксируется не больше двух раз (по разу с каждого конца), каждая релаксация добавляет не больше одной записи в корзину. Итого записей O(r + E) = O(r).
- Суммирование задержек — O(r).

Итого O(r + E + L) = O(r). Память также O(r).

Пример из программы: 8 маршрутизаторов, точки входа 1 и 5, суммарная задержка 30. Результат совпадает с обычным Дейкстрой на куче, это проверено ещё на 200 случайных сетях.

## Задача 2. Свадебное путешествие

**Модель.** Ориентированный невзвешенный граф: вершины — c городов, рёбра — f прямых рейсов (откуда → куда). Нужен маршрут home → t₁ → t₂ → t₃ → home, где t₁, t₂, t₃ — три туристических города в любом порядке, с минимальным общим числом перелётов. Стоимость и время не важны, поэтому вес каждого рейса 1, и кратчайший путь — это путь с наименьшим числом рёбер, его находит обход в ширину (BFS), Дейкстра не нужен.

**Алгоритм.**

1. Запустить BFS из четырёх городов: home, t₁, t₂, t₃. Каждый BFS даёт число перелётов до всех городов и массив предков для восстановления пути. Так получаем dist(x, y) для всех нужных пар, где x и y из {home, t₁, t₂, t₃}.
2. Перебрать все 3! = 6 порядков посещения (tᵢ, tⱼ, tₖ) и для каждого посчитать dist(home, tᵢ) + dist(tᵢ, tⱼ) + dist(tⱼ, tₖ) + dist(tₖ, home). Если какое-то расстояние бесконечно, порядок невозможен.
3. Выбрать порядок с минимальной суммой и склеить четыре пути, восстановленные по предкам.
4. Если ни один порядок невозможен, сообщить, что такой маршрут построить нельзя.

**Корректность.** Маршрут обязан посетить три города в каком-то порядке, и между соседними остановками выгоднее всего лететь кратчайшим путём, который отрезки друг от друга не зависят. Перебрав все 6 порядков, мы гарантированно найдём оптимальный.

**Время работы.** Четыре BFS по O(c + f), перебор 6 порядков O(1), восстановление пути O(c). Итого O(c + f) — линейно от размера входа. Память O(c + f).

Пример из программы: из Ростова в Мале, Пхукет и Стамбул — 7 перелётов: Ростов → Москва → Дубай → Мале → Дубай → Пхукет → Стамбул → Ростов.
